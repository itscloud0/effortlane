## Threads

I keep running into a simple problem with coding agents: choosing a cheaper model
is easy. Knowing whether it actually gets the work done with less usage is harder.

I'm building Effortlane to test that. It routes model and reasoning effort for
Codex CLI while keeping native login and execution. Shadow lets you compare its
recommendations with what actually ran.

There's now a one-command installer for macOS. Desktop stays native; Claude
support is an experimental Shadow observer. Subscription savings aren't proven
yet—that is exactly what I want to measure with real completed tasks.

If you use Codex heavily and want to help test it:
https://github.com/itscloud0/effortlane

## LinkedIn

I’m building Effortlane, an open-source model and reasoning-effort router for
coding agents.

The target isn't the cheapest next inference. It's less subscription usage per
correctly completed engineering task—including retries and follow-up fixes.

The current implementation supports Codex CLI on macOS with native ChatGPT
login and execution. Shadow records proposed routes without applying them, and
telemetry stays local. Desktop remains native. Claude support is an experimental
Shadow observer, with live validation still pending.

The next milestone is evidence: accepted tasks, rework, completion time, cache
behavior and allowance consumption across comparable work. I’m not claiming a
savings percentage before that comparison exists.

I’m looking for a small group of heavy Codex users to try the installer and one
real task, then help identify what needs fixing.

Source, setup and current evidence:
https://github.com/itscloud0/effortlane
